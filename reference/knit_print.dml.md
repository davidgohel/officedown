# Render a plot as a Powerpint DrawingML object

Function used to render DrawingML in knitr/rmarkdown documents. Only
Powerpoint outputs currently supported

## Usage

``` r
# S3 method for class 'dml'
knit_print(x, ...)
```

## Arguments

- x:

  a `dml` object

- ...:

  further arguments, not used.
